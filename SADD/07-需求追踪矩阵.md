# 07 需求追踪矩阵

> R = Requirement，A = Architecture，T = Test。  
> 状态：`覆盖` 表示设计已有明确方案与验收路径；`阶段` 表示 V1 分阶段交付；`预留` 表示仅做接口，不做 V1 实现。

| ID | 甲方需求 | 架构方案 | 验收 | 状态 |

## 6. 非目标声明

| 项目 | 原因 | 处理 |
| --- | --- | --- |
| 鸿蒙 V1 实现 | 原始需求仅要求预留接口 | 只保留 C ABI/NAPI |
| 社区公式库 | 原始需求未要求，UGC 合规成本高 | 后续专项设计 |

| 端侧大参数 VLM | 与轻量化和内存目标冲突 | 不规划 |
