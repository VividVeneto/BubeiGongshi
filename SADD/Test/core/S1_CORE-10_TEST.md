# CORE-10 测试方案

> 来源卡：[S1_CORE-10_引擎.md](../../core/S1_CORE-10_引擎.md)（直接求值与数值内核）。本文件是该卡“验收标准”字段的全文，按卡片编程时直接引用；修改卡片功能时同步修改本文件，卡片因阶段变化改名时本文件同步改名（`S编号_卡号_TEST.md`）。工具按卡片中的引用把本文件自“**验收标准**”行起的内容原样拼回卡片，本行以上不拼回。

**验收标准**
- [R12] 直接求值CX-01/02/06/07/08/10满足CORE-93保留的完整向量；基础Complex/Vector/Matrix、形状与域错误正确，非直接目标返回NotComputable而不调用求解模块。
- [R12] 全变量直接赋值输出值、单位与有效数字；除零/NaN/Inf/巨大指数/深度超限返回结构化错误；最坏不确定度区间符合CX-08。可逆链/多分支/bracket完整验收迁CORE-93。
- [R12] 单位：输出单位只允许与目标量纲相容的单位；换算精确或给出误差说明。
- [R12] 注入常数后结果逐项保留其值、来源与版本；优先级编排由 CORE-56 验收。
- [R19] 属性测试：随机赋值不 panic；超时 100 ms 内可取消。
