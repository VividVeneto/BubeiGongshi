- [R13] 规则表场景（输入 → 期望 validation / 诊断码 / 级别 / 定位 NodePath）：① `s=\int v\,\mathrm{d}t`，s 为 L、v 为 L T^-1、t 未声明 → Verified、无诊断（t 绑定为 T）；② `F=a\cdot b`，F 声明 Vector(3)，a、b 声明 Vector(3) → Invalid / TYPE_MATHKIND_MISMATCH / error / "1"；③ `a\times b`，a、b 声明 Vector(2) → Invalid / TYPE_CROSS_DIM / error / ""；④ `E=\tau`，E 为 L^2 M T^-2 且 kind Energy，τ 同量纲且 kind Torque → Unresolved / TYPE_QK_MISMATCH / warning / ""，换成 kind Heat 则 Verified 无诊断；⑤ `\omega=f`，ω 为 T^-1 Angle 且 kind AngularFrequency，f 为 T^-1 且 kind Frequency → Unresolved / 仅 TYPE_QK_MISMATCH（无 TYPE_DIM_CONFLICT）；`\omega=2\pi f` → Verified 无诊断；⑥ `Q=\theta m`，θ 声明 kind Temperature 量纲 Θ → Invalid / TYPE_AFFINE_MISUSE / error / "1"；θ₁−θ₂ 赋给 kind TemperatureDifference 的量不报；⑦ `v=3.3\sqrt{h}`，v 为 L T^-1、h 为 L：empirical=false → Invalid / TYPE_DIM_CONFLICT / ""；empirical=true → Unresolved / TYPE_EMPIRICAL_COEFF / warning，建议系数量纲为 `L^1/2 T^-1`。
- [R13] 运算规则表逐行最小用例：每个节点/函数行至少一条通过与一条违反（如 Pow 指数带量纲、root 次数非字面量且被开方式带量纲、floor 参数带量纲、Product body 带量纲、矩阵元素量纲不一、P 外的关系量纲为 1），诊断码与表一致；表外组合报 TYPE_MATHKIND_MISMATCH。det/伴随在阶数未知时按 P_f 规则：DX-08、DX-09 通过，`\det(A+B)=\det A` 得 VerifiedPolymorphic 而不错误合一。
- [R13] Angle 软约束与默认类型：未声明 x 时 `\sin x` Verified、x 绑定为无量纲；`\theta=\arcsin x`（θ 为 Angle）Verified；`\sin t`（t 为 T）仍 Invalid；Count 与基础量纲差异仍报 TYPE_DIM_CONFLICT。Number 为无量纲；未知 UnitRef 报 UNIT_UNKNOWN。QuantityKind 只在加减/关系/Piecewise 比较，乘除后为 None、一侧 None 不警告。
