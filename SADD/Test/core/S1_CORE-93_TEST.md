# CORE-93 测试方案

> 来源卡：[S1_CORE-93_引擎.md](../../core/S1_CORE-93_引擎.md)（受限反解与区间数值求根）。本文件是该卡“验收标准”字段的全文；修改卡片功能时同步修改本文件。工具按卡片中的引用把本文件自“**验收标准**”行起拼回卡片。

**验收标准**
- [R12] 计算向量 CX-01～CX-10 全部满足期望；自动 bracket 对 (x-2)(x+2) 首先返回正侧含2区间，对 (x+2)(x+3) 返回负侧绝对值较小的根所在区间；跨零极点 1/x 不得造出区间，采样点精确零直接成功。
- [R12] 用例测试（`tests/fixtures/calc/`）：全变量赋值输出值、单位与有效数字；可逆链反解输出表达式；x² = a 反解给出 ±√a 两支，a < 0 报 `EVAL_DOMAIN`（SX-06）；区间求根标注数值解、区间与残差；除零、NaN、Inf、巨大指数、深度超限返回结构化错误不崩溃。
- [R12] 单位：输出单位只允许与目标量纲相容的单位；换算精确或给出误差说明。
- [R12] 注入常数后结果逐项保留其值、来源与版本；优先级编排由 CORE-56 验收。
- [R19] 属性测试：随机赋值不 panic；超时 100 ms 内可取消。
- [R12] 完整evaluate/solvable_targets门面单向调用CORE-10直接内核；Direct/Symbolic/NumericOnly/NotComputable能力与实际行为一致，CORE-10不依赖本卡。
- [R16] `isolate`（CO-28）：`F = ma` 对 a 返回一支 `F/m`；`v = s/t` 对 t 返回一支 `s/v`；`x^2 = a` 对 x 返回两支 `\sqrt{a}`、`-\sqrt{a}` 且次序固定；`x = x + 1` 对 x、`\int x\,dx = y` 对 x 返回 `EVAL_NOT_COMPUTABLE`；预置取消返回 `EVAL_TIMEOUT`；CX-03/CX-04 的 evaluate 符号步骤与 isolate 结果逐节点相等（同一实现）。
