**验收标准**
- [R18] 干净检出仅本卡产物：cargo metadata --no-deps 列出fml-error且无server；cargo build --workspace、cargo fmt --all --check、cargo clippy --workspace --all-targets -- -D warnings成功。fml-error仅文档/lint骨架，无伪造领域API；其他未实现crate不预列成员。app/内flutter analyze与flutter test可在无FFI/无平台工程下运行，空壳Widget用本卡测试启动，不能依赖后卡。
- [R18] 配置交付清单逐项存在且可解析，目录骨架与说明齐全；rust-toolchain含rustfmt/clippy；analysis_options显式启用public_member_api_docs，临时负例验证缺文档确会失败；workspace lint被骨架继承。deny.toml 逐项断言：licenses、bans、sources 三域同时存在；`[licenses] allow` 为显式 SPDX 数组、无通配与按大类写法，且每一项都能在锁文件某个包的许可表达式里找到；自有 `publish = false` 的 crate 由 `[licenses] private = { ignore = true }` 忽略，而不是为它编造 license；`[bans] deny` 为空数组（禁用名单只由用户或发布政策登记），`[bans.workspace-dependencies]` 的 duplicates、unused 为 deny；`[sources] unknown-registry`、`unknown-git` 均为 deny，`allow-registry` 只含 crates.io index，`allow-git` 为空。基线 `cargo deny check licenses bans sources` 对交付锁文件退出 0；合成夹具（临时 workspace + 许可不在 allow 的合成包）必须非零退出并指出该许可，删除夹具后其余验收仍通过。许可抄录按卡 :93 的 (a)：锁文件中第三方包（含开发依赖）的 SPDX 逐项进 allow 并计入 PR 证据，SBOM/THIRD_PARTY_NOTICES 归 CORE-42；许可接受是否需用户逐项裁决是待决政策（附录 D CO-48），不作本卡自动门禁，若 lead 决定要求人工裁决则记 PR 手动 checklist（裁决人/日期/结论）。不以字体或数据许可当 Cargo 许可白名单。
- [R18] 四个核心锁版文件可解析且值为精确版本；tools/toolchain.versions额外有queried_date=YYYY-MM-DD及本卡首用的cargo_deny=精确版本，与ADR-V5-15查询记录一致；测试断言cargo deny --version与锁值相符后才执行许可证门禁，不能用未锁版工具通过验收；app/.flutter-version只含版本，requirements.txt固定依赖。尚未到各自首用卡的锁文件/平台版本明确未创建，不伪报齐全；CI读取版本的集成由CORE-41后续验收（下游说明，非契约：CORE-41），不是本卡前置。
- [R18][R26] 本卡四份policy按契约格式解析并与卡片初始值逐项一致：dep-allow包含所有预留包与错误/取消例外，pack→store和store→sync允许且反向不允许、全图无环；dep6_symbols头/精确op/type行合法；platform-check-patterns含别名规则；network-construction只允许两个platform/net目录，不豁免composition/privacy。这里只核对合法策略输入的结构与初值：断言落点为 crates/fml-error/tests/sadd_policies.rs（本卡唯一 crate 的集成测试，随 cargo test --workspace 执行），逐文件断言顶层 version 为 1、键集合与卡片初始表逐项一致且无多余键、dep-allow 落盘值为完整 Cargo package name 且无自依赖、dep6_symbols 的唯一头行与 op/type 行集合、platform-check-patterns 的三元组集合、network-construction 的 allow 只含两个 platform/net 目录且不豁免 composition/privacy；YAML/JSON 解析用开发依赖 `serde`、`serde_json`、`serde_yaml_ng`（版本由该卡编码会话按 ADR-V5-15 锁入 Cargo.lock，测试方案不预列版本），也不把它写成第二套拒绝器；这些包的锁文件 SPDX 按本文件第 2 条（deny.toml 断言）抄进 `[licenses] allow` 并计入 PR 证据；许可接受是否需逐项裁决同样按第 2 条作待决政策处理，不写成本卡阻断；未知字段/版本/重复或非法行的拒绝，以及词法识别与真实源码反例，由CORE-69后续验收（其测试方案第2条已承接；下游说明，非契约：CORE-69），不能循环作为首卡前置。
