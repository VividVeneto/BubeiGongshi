**验收标准**
- [R18][R26] 每条DEP/PRIV规则至少正反例各1：注释/字符串无误报，真实违规返回1并带正确行号；未闭合字符串或块注释返回2、括号不平衡不报错；ui内ctx.http（AppDeps字段）正例通过、composition外PlatformPorts.http反例失败、接收者类型不可判定的.http为warning且生成checklist；退出2只走GATE-1——stderr单行 `<path>: GATE-1 <message>`、stdout为空、不输出部分Finding（与具体文件无关的环境错误path为 `-`），四份policy各造缺失/未知字段/版本非1/重复键四类，均退出2且不降级为0。
- [R18] CI和本地同一输入Finding字节相同；普通/前缀import别名与Cargo package alias正反例覆盖；`tokens(path)` 未给language时按 `LANGUAGE_BY_SUFFIX` 判定（`.rs`/`.dart`/`.h`/`.cpp` 各一例）、未登记后缀报2，`scan_tree` 返回(仓库相对路径, Token)并按路径字典序。
- [R18] DEP-1正反例覆盖fml-error/fml-ast取消例外、server→sync-proto、pack→store（PackCatalog只读适配，不报DEP-3）、store→sync允许；server→store/ffi、store→pack、sync→store及其他领域→store拒绝；`dep = { workspace = true }` 与 `alias = { path, package }` 按真名解析、`path` 指向仓库外报2；dev/build/target边及Cargo alias不能绕过；仅预留但尚未实现的包不产生缺包错误，已实现包缺策略条目报2（GATE-1）。DEP-3对13个领域crate加fml-sync同一判定，领域crate→fml-store/fml-ffi即使已登记在dep-allow.yaml也报DEP-3，与DEP-1同边时只报DEP-3。DEP-4只扫 `crates/**/*.rs`：`contracts/include/fmlcore.h` 与C++文件的同名文本不报、`crates/fml-ffi/src/` 内不报、字符串/注释内不报。DEP-5(a)覆盖ui导入 `package:http`/`package:dio`、导入 `binding/`（仅 `binding/dto/*.g.dart` 豁免）与 `platform/`、构造参数或字段出现AppDeps/CoreBinding/PlatformPorts；(b)覆盖 composition 外读取 `PlatformPorts.http` 报error、`app/lib/composition/` 内同类读取不报、`AppDeps.http` 不报error（类型不可判定时只warning）；同一import同时命中DEP-5与PRIV-1时只报DEP-5，同文件另一处构造各自报一条。DEP-6精确op调用字符串与type token被拦，注释和普通说明字符串不拦，`app/lib/platform/**` 以外的Dart文件不扫。无法证明的间接封装输出warning和人工项，不作为自动通过。
- [R20] 注释token保真：`///`、`//!`、`/* */`、`/** */`、`// SAFETY:`、Rust嵌套块注释、Dart三引号与raw字符串夹具给出预期kind/line/offset（offset按UTF-8字节、`\r\n` 只增一行、U+2028不计行、Rust生命周期判code、字符字面量判string、字符串内 `//` 不产生注释token、注释内引号不开启字符串）；CORE-74的UNSAFE-2与CORE-71的Dart复杂度按kind消费。阶段1交付时词法/Token/GATE-1条目应可独立跑通，阶段2再跑DEP/PRIV条目。
