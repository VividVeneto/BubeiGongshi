# 08 需求追踪矩阵 v2.1

> R = Requirement，A = Architecture，T = Test。  
> 状态：`覆盖` 表示设计已有明确方案与验收路径；`阶段` 表示 V1 分阶段交付；`预留` 表示仅做接口，不做 V1 实现。

> 2026-10-10 补充确认：高中内容和云端 API 的 LLM 识别均为现有需求。分阶段交付、按需下载和用户按次授权不表示需求可以暂缓。
