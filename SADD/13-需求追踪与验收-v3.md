## 🧮 正确性验收

| ID | 用例/样本 | 通过标准 |
| --- | --- | --- |
| T-EDIT | 至少 100 个冻结语法代表式，含中文 IME、Unicode、分数、矩阵、积分/求和；超深输入/禁用命令 | 原文可恢复、语义往返、错误定位正确；不执行宏/外部引用；不支持内容明确标记 |
| T-DIM | `F=ma`、`F=m+a`、`df/dt`、`∫F dx`、向量点叉积、场/坐标、Unknown、概率密度 | 正例通过，错误/未知不被标 Verified；跨端输出规范 AST/诊断一致 |

| T-SUB | `a=dv/dt` 代入 `F=ma`；能量/力矩；同名积分变量；多值反解；母修订被引用 | 类型/关系/条件均检查；变量不捕获；分支显式；推导循环/超预算拒绝 |

## 📷 识别、图片与 GC 验收

| ID | 场景 | 通过标准 |
| --- | --- | --- |
| T-PLUGIN | 插入两个模拟后端与一个真实本地模型 | 不改 UI/领域核心即可切换；能力不符拒绝；模型/词表版本可追踪；取消后资源回收 |
| T-OCR | 冻结集≥1000 个表达式、≥50 位作者，包含墨迹渲染与实拍、阴影/倾斜/弱光/细符号 | 按作者及表达式模板分离训练/验证/测试；报告实际 Top-1/Top-3 结构准确率、可解析率、平均校正次数和失败类别 |
| T-IMAGE | JPEG/PNG/静态 WebP，12MP、40MP边界、20MiB边界、畸形头、错误EXIF、极窄长图 | 预览/裁剪正确，不先全尺寸 UI 解码；超限可理解拒绝；源文件 hash不变；灰度/增强可切换 |
| T-GC | N=0/1/5/100，越界/非整数，6次默认、101次最大、100→0、并发/逆序终态 | 终态可访问历史≤N、包含实际图与结果；不因固定/采纳豁免；清空不删库中独立另存内容 |
| T-GC | 逐步骤进程中断、磁盘满、文件被占用、设置并发、失败/取消/未决到期 | cleanup_job可恢复、无遗失清理任务；启动/重试后受控目录无孤儿；不跟随链接删除外部文件 |
| T-GC | 本机库/WAL/cache、缩略图、导出、系统备份和云同步检查 | 无明文公式/图落盘，无历史进默认备份/同步；明确逻辑删除与擦除限制，不作不可验证保证 |
| T-CLOUD | 两端注册、逐次授权、实际模型联调、无网络/429/5xx/超时/取消 | 游客/无授权拒绝，图片hash变更重授权，返回不可信候选须校验 |
| T-CLOUD | ACK丢失、重复键、换图复用键、worker提交后崩溃、客户端重启 | 同图同键返回同job；换图409；上游不确定为UNKNOWN且不自动再付费；重启只查询 |
| T-CLOUD | 网关/tmp/APM/代理日志、结果过期、供应商政策核实 | 临时图目标60s内清理、崩溃TTL≤1h、结果≤24h；供应商边界准确披露，凭据不出客户端 |

识别质量预算（M0 冻结前的候选门槛）：清晰墨迹/规范图 Top-1≥85%、真实拍照 Top-1≥75%，分别报告，不混成一项“准确率”；AST 结构匹配先做允许的规范化，不能借量纲强制修正答案后算命中。至少1000样本报告分组置信区间与漏检；关键负号、上下标、分数线错误单独统计。门槛需用实际模型证明；未通过则阻止该识别能力上线或经产品批准修改范围，不能仅宣称“支持人工改”就视为识别达标。

去噪/增强采用同一测试集 A/B；报告识别准确率与校正次数变化，不仅报告画面“更清晰”。YOLO 的检测 AP/召回与端到端公式 Top-1 是不同指标，实验方案另在实验分支。

## ⚡ 可复现性能预算

使用 release 构建、锁定应用/核心/包/模型版本，飞行模式测本地路径；冷启动至少30次，核心操作≥1000次，图像管线≥100张、连续20张压力；记录P50/P95与峰值。基准设备在M0登记具体型号/SoC/OS/电池/温度，禁止以模拟器替代真机结论。

| T-PERF 指标 | Android 基线：4GB RAM arm64 中端机 | Windows 基线：4核/8GB/SSD/Windows11 x64 |
| --- | --- | --- |
| 冷启动到可操作游客首页 P95 | ≤2s | ≤1.5s |
| 编辑解析+量纲 P95 | ≤30ms（≤256节点） | ≤15ms（同输入） |
| 列表/普通交互 | 60Hz下P95帧≤16.7ms，>32ms长帧<1% | 同标准，含150/200%DPI |
| 空闲内存 | PSS≤150MiB，无模型/相机/活动识别 | Working Set≤250MiB，同条件 |
| 图像+本地推理峰值 | PSS≤320MiB，工作图≤2048px、已锁模型 | Working Set≤500MiB，同模型等级 |
| 预处理P95 | ≤500ms（工作图≤2048px，解码另记） | ≤300ms（同工作图） |
| 本地单公式识别P95 | ≤3s（锁定模型输入，解码另记） | ≤2s |
| 压力/释放 | 连续20张12MP图无OOM，任务结束60s内回落至空闲+20MiB | 无泄漏趋势，回落至空闲+30MiB |
| 基础分发体积 | 单ABI APK≤70MiB；权重和扩展包单列 | 压缩安装器≤90MiB；权重和扩展包单列 |

这些预算未实测，若渲染/SQLCipher/模型运行时使预算无法达到，M0通过ADR调整具体实现或预算并让需求负责人接受，不能直接修改测量口径。

云识别不承诺无条件“<5秒”：建议受控正常网络样本P50≤5s、P95≤15s，队列和供应商时延分别记录；超过处理上限进入明确状态。费用按任务/供应商用量与重复提交数计量。后端以每账户配额和并发上限控制成本，容量测试结果决定扩容。
