## 📦 通用资源包的边界

资源包是平台无关的 UTF-8 数据、字体、图片和模型权重集合，Android/Windows 对同一内容使用相同 pack ID、版本和 hash。平台加载位置、字体注册 API、native 推理运行时属于适配器，不能要求同一 `.so/.dll` 在两端使用。

| 包 | 内容 | 安装方式 |
| --- | --- | --- |
| bootstrap | 最小符号清单与字体、SI 单位与常数集、默认记号方案、必要本地化、学习示例 | 随安装包，仍经统一资源目录和验证器加载，首次启动不联网 |
| university-calculus | 同济《高等数学》第八版范围 + 考研数一、数二、数三的高等数学（微积分）部分，范围标签细到知识点 | 主动下载/离线导入 |
| university-linear-algebra | 行列式、矩阵、向量组、线性方程组、特征值与相似对角化、二次型；向量空间（仅数一） | 主动下载/离线导入 |
| university-probability-statistics | 随机事件与概率、随机变量及其分布、数字特征、极限定理、抽样分布、参数估计、假设检验（数二不考） | 主动下载/离线导入 |
| university-physics | 2023 年版《理工科类大学物理课程教学基本要求》范围，按 A 类、B 类、扩展、中学衔接分层 | 主动下载/离线导入 |
| hs-math-required、hs-math-elective-required、hs-physics-required、hs-physics-elective-required | 高中数学与物理（H01），按课标必修与选择性必修分包 | 独立分包，不替代大学内容 |
| model-hmer-* | 权重、词表、预处理与 decoder 配置、模型卡、授权登记 | 不随主包，用户主动安装 |
| font-extension / locale-* | 扩展字体、本地化与语义朗读 | 按需加载，与许可清单关联 |

课程包的组成与 10 §静态资源 一致：公式条目（FormulaItem 与固定修订）、公式书 Book（章节树与条目清单）、题目与干扰项、易混组 ConfusableGroup、题型模板、记号方案与常数集。V1 界面与课程内容只提供简体中文；locale-* 是扩展点，不计入 V1 交付。

“资源剥离”指课程/字体/模型可独立构建和版本化，不要求 bootstrap 首次在线获取。bootstrap 只放首启必需资源，课程包与模型包不计入安装包体积；安装包体积与渲染、搜索等性能预算见 13 §可复现性能预算。渲染库自带字体需在构建时纳入同一资源目录/清单；字体按实际单独许可处理（见 §版权边界），不能把程序代码许可证直接视为字体许可。

包内禁止出现 `.so`、`.dll`、`.exe`、可执行脚本与动态库。同一资源包在两端加载后，条目数、逻辑 ID、规范化 AST 哈希与诊断必须一致，由 T-PACK 验收。

### 包内的记号方案、常数集与符号清单

NotationProfile、SymbolAlias、ConstantSet 的语义与规则定义在 10 §记号方案与常数集，本节只规定包内如何携带。

| 包内目录 | 内容 | 规则 |
| --- | --- | --- |
| `notation/` | 每个 NotationProfile 一个条目：profile_id、版本、课程、textbook_id、字形 → SymbolId 规则、函数记号约定、分布参数化约定，以及它的 SymbolAlias 列表 | 课程包声明默认方案与可选方案；条目用 `notation_profile_ids` 声明已审校的方案，未审校方案不可选；构建期运行字形冲突检测，出现 NOTATION_AMBIGUOUS 不得发布 |
| `constants/` | ConstantSet 中的 exact 与 textbook 两类：版本、来源（CODATA 版本或 textbook_id）、值、单位、精度 | given 值不进常数集文件，随题目条目携带；常数集换版生成新修订，已发生的复习记录不改写 |
| `symbols/` | 符号清单：以 ISO 80000-2 符号表为基准、GB 3102.11 为国内对照，每个符号记 Unicode、LaTeX、语义 ID 与能力分级（可输入、可渲染、可计算） | 清单内每个符号的 Unicode↔LaTeX 往返与渲染由 T-EDIT 验收；条文以采购的标准文本为准，本次只核对了 GB 3102.11 的公开转录（S24） |

国内大学物理默认方案沿用通行记号：ν 为物质的量、n 为分子数密度、k 为玻尔兹曼常量、V 为体积、v 为速度；线性代数默认方案中 A* 为伴随矩阵。GB 3102.11 允许 tg、arctg、cosec 作为 tan、arctan、csc 的替代写法，并规定不带底数的 log 不能代替 ln、lg、lb，这些在符号清单中归一到同一函数 ID 或标为需要指定底数。记号方案的切换与常数取值分别由 T-NOTATION、T-CONST 验收。

## 🛡️ 清单、签名与激活

### 格式契约

包以受限 ZIP 容器示意，`manifest.json` + `manifest.sig` + `entries/`，最终格式在 M0 冻结。清单原始 UTF-8 字节参与签名，不允许 JSON 重排后“重验签”；解析器拒绝重复 key 和非标准数值。签名使用 Ed25519，条目用 SHA-256；不同时引入多套哈希算法。

```json
{
  "format_version": 1,
  "pack_id": "university-physics",
  "pack_version": "1.0.0",
  "security_epoch": 1,
  "key_id": "content-2026-a",
  "engine_abi_major": 1,
  "ast_schema": 1,
  "compatible_app": ">=1.0.0 <2.0.0",
  "dependencies": [],
  "entries": [],
  "licenses": [],
  "provenance": []
}
```

该示例只展示字段，不是可发布空包。发布验证器必须拒绝缺少内容、许可、来源的课程/模型包。每个 entry 含相对路径、类型、解压长度、SHA-256、逻辑 ID；课程条目另含范围标签、来源与校验 schema，模型另含 tensor、词表和内存约束。

### 安装顺序和攻击面

1. 下载至私有 staging，断点续传按内容 hash 和长度校验；公开包下载不上传学习数据。
2. 读取受限清单（初始≤1 MiB）和签名，使用程序内置/受信更新的公钥根验签；先验证签名再处理内容。
3. 验证版本、依赖无环、ABI/AST/格式兼容、条目数量≤10000。初始包压缩体积≤256 MiB、解包≤512 MiB、单条≤128 MiB，模型若需例外必须另经预算 ADR，不能无限解压。
4. 限制压缩比≤100，拒绝绝对路径、`..`、盘符/UNC、混淆斜线、重复路径、NTFS ADS、保留设备名、符号链接/重解析点和平台大小写碰撞。只将经过规范化且保持在目标私有目录的相对路径解包。
5. 流式解压、逐项验证长度/hash；模型不含任意代码/custom ops 动态库，图算子/张量维度受限。签名不代表模型天然安全，解析器与运行时仍需预算。
6. 以内容 hash 创建新的只读版本目录，写入完成标记，fsync/平台等价持久化后切换小型 `active.json` 指针。正在读取旧包的会话继续使用旧句柄，结束后回收。
7. Windows 若 rename 因句柄占用失败保留旧指针，延迟激活，不覆盖原目录。崩溃恢复只接受有完成标记且验证过的目录，删除未激活 staging。

离线导入遵守相同验签流程；用户自定义公式是用户数据，不伪装成受信课程包。开发者 unsigned 模式只在开发构建，正式版本不可从隐藏开关绕过。

### 信任根、防降级和回退

清单签名加版本号不足以完全防止重放、冻结和签名密钥失窃。正式在线更新采用成熟 TUF 客户端/框架的 root、targets、snapshot、timestamp 元数据流程，参考规范 [S06]，不自己设计不完整“类 TUF”协议。离线 bootstrap 与离线包走受信根和兼容策略，不依赖首次联网取得 timestamp。

信任根离线保管，发布自动化只持有限 targets 权限；根轮换由旧/新阈值签名验证，密钥撤销和安全 epoch 随应用或已受信根更新。客户端记住已见的最高安全序号/元数据版本，过期或时钟异常暂停在线更新并提示，现有已验证内容仍可使用。

“内容版本回退”和“安全防降级”分开：仅允许回到本机已验证、未撤销、同一允许安全 epoch 且与当前应用兼容的最近良好内容版本；拒绝任意远端旧包。禁止把安全 epoch 回退作为普通修复手段。应用版本与数据库迁移的回滚按 10 §数据、资源与服务端 处理。

## 📚 课程基线与覆盖矩阵

“同济高数 + 考研数学全部范围”按“基线版本 → 知识点 → 条目”三层交付：考试范围以冻结的大纲知识点计算，教材只作对齐索引。基线版本的决定见 00 D-17，内容来源策略见 00 D-11 与 ADR-014。

冻结规则：

1. 网络转录只作线索，不作冻结依据。教育部教育考试院网站“考试大纲”栏目最新只有 2022 年数学大纲且正文为空（S17）；第三方转录互相矛盾且有错，例如有媒体称 2027 年数三“新增边际与弹性”，而 2025 年大纲原文已有“导数的经济意义（含边际与弹性的概念）”；另有网站把常系数线性微分方程组列入数一，而数一原文没有这一项（S20）。
2. syllabus_item 记录 kp_id、适用科目集合、要求层级、纸本页码、两位转录人与冻结时间。资源包只携带 kp_id、自编摘要与页码，不复制大纲全文。
3. 新一年大纲发布后按同一流程转录，并与上一版逐条比对；差异生成新的 syllabus_id 与条目修订，旧版本保留，用户按目标考试年份选择。

### 知识点与范围标签

- **知识点**是冻结大纲“考试要求”中最小的可判定子句，带 kp_id、适用科目集合（数一、数二、数三）、要求层级（了解、理解、掌握、会用；大纲中“会求”“会用”一类子句归入会用）和来源页码。大学物理用 `phys_req_id`，高中用课标条目号。
- **exam_scope 下沉到知识点**：同一公式可能只部分适用于某一科目，例如定积分应用，数三只考面积、旋转体体积、平均值和经济应用。条目的 exam_scope 取其所引知识点的并集，部分适用时用 `scope_note` 写明。
- **带星号不等于不考**：同济第八版中伯努利方程、欧拉方程、混合积、二元函数二阶泰勒公式、通量与散度、环流量与旋度带星号，但数一要考；方程的近似解、积分表的使用、微分与定积分的近似计算、幂级数的应用不带星号，却不在考纲内。
- **无公式的知识点**（如纯概念辨析）显式标为 `concept_only` 并配概念卡后计入覆盖，不得以“无公式”跳过。
- 没有确认适用大纲的条目保持 `scope_review_pending`，不计入“考试范围已覆盖”。覆盖率口径、抽检比例与错误率阈值见 13 的 T-CONTENT。

### 版权边界

- **公式事实可以自编录入**：《著作权法》第五条规定该法不适用于“历法、通用数表、通用表格和公式”（S30）。公式本身、成立条件和符号含义按事实自行编写。
- **教材表述是作品**：教材的具体表述、章节编排、例题、讲解与插图受保护。资源包只引用书名、版次、章节号、页码与例号作为对齐索引，解释、易错点、例题与情境题自编。
- **真题**：以年份、科目、题号和考点统计的形式引用，用于“考试语境”与考频统计；题干原文的使用需单独授权评估，未授权前不进包。
- **共享许可的文本不进包**：维基百科文本为 CC BY-SA 4.0 与 GFDL（S26），相同方式共享义务会延伸到资源包中的衍生表述；OpenStax 教材为 CC BY-NC-SA 4.0 并限制生成式 AI 用途（S13）。两者只供人工参考。
- **字体**：渲染库内置字体逐个登记许可，随包附许可文本。KaTeX 字体的许可在审查稿中记为 SIL OFL，而 katex-fonts 仓库根 LICENSE 为 MIT（S29）；以实际分发的字体文件及其上游声明为准，核实前不发布。
- **生成式工具辅助**：用大模型起草的解释、干扰项与易错点按自编内容走同一审校流程，并记录生成工具与版本；不把非商业许可或禁止生成式 AI 用途的材料作为生成输入。

处理器只读取文本/数据，不执行 `latex`、仓库脚本、notebook 或宏。去重使用规范 AST + 条件 + 符号映射的 hash，不只比较 LaTeX 字符串。量纲通过不能证明公式正确；审校人必须检查来源、系数、符号含义、边界和适用条件。

- 作者与审校者不得为同一人；记录双方、时间、修订与分歧，审校分歧率写入 13 的验收记录。
- 错误分级：**严重错误**为系数、正负号、指数、上下限、成立条件、适用范围、量纲之一出错；**一般错误**为措辞、排版、缺别名。抽检规则与阈值见 13 的 T-CONTENT。

## 🧪 模型、许可与供应链门禁
