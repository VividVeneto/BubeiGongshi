# 03 平台实现规范 v2.0

> 本文档只定义平台差异。领域规则、数据模型、核心 API 以 `02-软件架构设计-v2.md` 为准。

## 1. 平台共性契约

各平台必须实现同一组适配接口：

| 接口 | 职责 |
| --- | --- |
| `SecureKeyValueStore` | 保存密钥元数据、token、恢复码提示 |
| `LocalFileStore` | 私有数据库、资源包、识别历史目录 |
| `ImagePicker` | 文件管理器、相册、剪贴板选图 |
| `CameraController` | 拍照、取景质量提示 |
| `NotificationScheduler` | 复习提醒 |
| `BiometricPrompt` | 可选本机解锁 |
| `ClipboardAdapter` | 文本/图片输入输出 |
| `RuntimeInfo` | 系统版本、屏幕、可用内存、语言 |

平台层不得包含：

- 公式解析逻辑。
- 量纲和单位换算。
- 排版布局。
- 复习调度。
- 同步冲突合并。
- 资源包签名算法。

## 2. Android 实现

## 2.1 构建与产物

| 项 | 要求 |
| --- | --- |
| 最低支持 | Android 8.0（API 26），可按数据另行调整 |
| 目标版本 | 当前 Google Play / 国内分发要求 |
| ABI | `arm64-v8a` 必须提供；`armeabi-v7a` 视用户数据决定 |
| 核心库 | Rust 编译为 `libfmlcore.so` |
| 产物 | AAB 用于商店，APK 用于官网/测试分发 |
| 体积 | 核心安装包不含可选识别模型 |

## 2.2 权限

| 权限 | 策略 |
| --- | --- |
| `CAMERA` | 仅拍照功能运行时申请，拒绝后仍可用相册/文件管理器 |
| `POST_NOTIFICATIONS` | 用户开启复习提醒时申请 |
| 网络 | 仅注册同步、云识别、资源包下载时使用 |
| 存储 | 不申请 `READ_EXTERNAL_STORAGE`、`WRITE_EXTERNAL_STORAGE`、`READ_MEDIA_IMAGES` |

相册使用 Photo Picker；文件管理器使用 SAF。不要申请宽泛存储权限。

## 2.3 图片选择

### 系统相册

- Android 13+ 优先 Photo Picker。
- 低版本使用 `ACTION_PICK` 或 SAF。

### 文件管理器

使用：

```text
Intent.ACTION_OPEN_DOCUMENT
CATEGORY_OPENABLE
type = image/*
EXTRA_ALLOW_MULTIPLE = true
```

处理原则：

1. URI 只在当前导入会话内使用，不作为长期资产。
2. 立即复制到私有临时目录，后续处理自有副本。
3. 通过 `ContentResolver.openInputStream` 流式读取。
4. 不在 Dart 层解码全尺寸 Bitmap。
5. 处理结束删除临时副本。

### 相机

- CameraX 或系统相机 Intent。
- 优先 YUV/流式路径。
- 取景阶段提示清晰度、亮度、阴影、倾斜和公式占比。
- 相机资源使用完立即释放。

## 2.4 存储路径

| 数据 | 路径 | 说明 |
| --- | --- | --- |
| 本地库 | `noBackupFilesDir/database` | 不参与系统自动备份 |
| 资源包 | `noBackupFilesDir/packs` | 私有、只读打开 |
| 识别历史 | `noBackupFilesDir/recognition` | 加密存储 |
| 临时文件 | `cacheDir/tmp-import` | 会话结束清理 |
| 导出文件 | SAF 用户选择目录 | 仅用户主动操作 |

## 2.5 密钥与加密

- Android Keystore 生成硬件保护密钥。
- 数据库主密钥和图片历史密钥由 Keystore 密钥加密。
- 设置 `FLAG_SECURE` 提供为可选开关，默认关闭。
- 强密钥备份受 Keystore 限制，必须提示用户启用注册同步或导出加密备份。

## 2.6 进程生命周期

- 编辑草稿防抖 500 ms 落盘。
- 未提交墨迹保存到本地草稿。
- 复习会话记录进度，冷启动询问是否继续。
- 后台进程被杀后不得依赖常驻服务。
- GC 在 `onTrimMemory` 时兜底触发，但不阻塞主线程。

## 2.7 通知与复习提醒

- 本地 AlarmManager/WorkManager。
- 提醒内容不展示用户私有公式正文，默认显示课程和卡片数量。
- 提供提醒自检：通知权限、精确闹钟、电池优化、厂商自启动。
- 国内 ROM 适配表按厂商维护，并提供跳转设置引导。
- V1 不接入厂商推送。

## 2.8 输入与 UI

- 手写板支持触控笔、压感、历史触点、手掌误触过滤。
- 进入手写板时收起 IME。
- 公式编辑优先级：符号面板/结构化 > 手写 > LaTeX。
- 大屏和折叠屏使用双栏布局。
- 返回手势逐层退出面板。
- 支持深色模式、动态字号、高对比度。

## 3. Windows 实现

## 3.1 构建与产物

| 项 | 要求 |
| --- | --- |
| 目标 | Windows 10 1809+ x64 |
| UI | Flutter Windows |
| 核心库 | `x86_64-pc-windows-msvc` 编译为 `fmlcore.dll` |
| 分发 | 官网安装器为主，MSIX 可选 |
| 签名 | 必须代码签名；SmartScreen 声誉提前建立 |
| 体积 | 安装器 ≤ 70 MB，不含可选模型 |

建议安装器：

- Inno Setup 或 WiX。
- 安装到 per-user 目录，默认不要求管理员权限。
- 创建开始菜单快捷方式以支持 Toast。
- 卸载时保留用户数据，并提示导出或删除。

## 3.2 文件选择

必须支持：

1. 文件管理器选择图片：`FileOpenPicker` 或 Win32 `IFileOpenDialog`。
2. 拖拽导入。
3. 剪贴板粘贴。
4. 扫描仪导入可作为后续增强。

约束：

- 使用流式解码。
- 支持常见格式：PNG、JPEG、WebP、HEIC 若系统解码器可用。
- 超大图片先降采样。
- 多显示器 DPI 下预览不模糊。

## 3.3 存储路径

| 数据 | 路径 |
| --- | --- |
| 本地库 | `%LOCALAPPDATA%\BubeiGongshi\database` |
| 资源包 | `%LOCALAPPDATA%\BubeiGongshi\packs` |
| 识别历史 | `%LOCALAPPDATA%\BubeiGongshi\recognition` |
| 临时文件 | `%LOCALAPPDATA%\BubeiGongshi\cache` |

不写入 `C:\Program Files`、用户桌面或公共下载目录。

## 3.4 密钥与加密

- 首选 DPAPI 绑定当前 Windows 用户。
- 可选 Windows Hello / Credential Vault。
- 必须告知限制：

1. 更换 Windows 用户账户后密钥可能不可恢复。
2. 同机管理员攻击不在 DPAPI 的防御边界内。
3. 卸载前应导出备份或完成注册同步。

## 3.5 窗口与 DPI

- 每显示器 DPI 感知。
- 记住窗口大小和位置，但不记住跨屏不可见位置。
- 支持最小化到托盘，退出前确认。
- 键盘快捷键完整覆盖编辑、复习、导航。
- 剪贴板公式可导出为 LaTeX、Unicode、图片三种格式。
- 提供可选“复制后自动清空剪贴板”。

## 3.6 更新

- 更新包签名校验。
- 下载支持断点续传。
- 安装前备份核心数据并校验磁盘空间。
- 失败自动回滚旧版本。
- 支持离线导入资源包。

## 4. HarmonyOS 接口预留

V1 不开发 HarmonyOS，但必须满足以下条件：

1. Rust 核心无平台依赖，可交叉编译。
2. 所有跨语言能力通过 C ABI 暴露。
3. 未来鸿蒙侧用 NAPI 包装同一 C ABI。
4. 平台适配接口在 Flutter 侧不直接耦合 Dart UI 状态。
5. 资源包格式不依赖 Android/Windows 文件系统特性。
6. CI 保留 `aarch64-unknown-linux-ohos` 编译冒烟。
7. UI 业务逻辑与 Widget 分离，未来可替换 ArkTS UI。

## 5. 双端行为一致性

| 行为 | 一致性要求 |
| --- | --- |
| 公式解析结果 | 完全一致 |
| 量纲错误 | 错误码与 NodePath 一致 |
| 计算结果 | 数值和单位一致 |
| DisplayList | 布局一致，允许光栅化差异 |
| GC 语义 | 保留次数和删除范围一致 |
| 游客数据 | 均本机私有 |
| 文件选图 | 均支持文件管理器 |
| 云功能 | 均需注册与显式授权 |

每项契约必须有跨平台测试用例，禁止只靠人工验收。

## 6. 平台验收清单

### Android

- 安装后无网络可启动并使用游客账户。
- 不申请宽泛存储权限。
- Photo Picker 与文件管理器均可选图。
- 1200 万像素照片连续导入 20 张不 OOM。
- 后台杀死后草稿恢复。
- GC 后私有目录无未加密图片残留。
- 中端机冷启动、列表滚动和公式排版达标。

### Windows

- 安装器签名有效。
- 高 DPI 下公式与 UI 不模糊。
- 文件选择、拖拽、剪贴板均可导入图片。
- 卸载保留数据且给出导出提示。
- 更新失败可回滚。
- GC 后 `%LOCALAPPDATA%` 中无未清理图片和缩略图。

### 双端

- 同一 LaTeX 输入产生相同 AST。
- 同一公式产生相同诊断和 NodePath。
- 同一变量赋值产生相同结果。
- 同一资源包双端均可校验加载。
- 游客升级注册后数据接管成功。
