## C.1 调查方法与结论

调查于 2026-10-18 进行：通过 GitHub 官方 API 搜索 `physics-formulary`、`physics formulary latex`，读取候选仓库的元数据、README、LICENSE 与 LaTeX 源文件；补充 Wikidata 计数以及 OpenStax、维基百科的许可。代码库、字体、模型权重和训练数据的许可分别审查，§C.2 不是对全部第三方素材的整体授权结论。

结论：

1. 开源库不能作为中文课程公式的主来源。Open_Physics 是意大利语且没有课程对齐；Wikidata 的中文条目和物理定律条目都太少；OpenStax 与维基百科的许可不允许其文本进入商业资源包。
2. V1 内容以自编为主（附录 A ADR-014 判定采纳），按 CORE-16 的条目字段与审校流程生产；开源资源只用于对齐、校验与单元测试，每项按 provenance 登记。
3. 公式本身不适用著作权法（S30），但教材、真题与百科的表述受保护：资源包只存出处与自编改写。
4. 开源工具（Pint、SymPy）用于单位、常数与恒等变形的离线交叉校验，不打包进客户端。

## C.3 试摄入样例

从 Open_Physics 固定版本 `source/b_formulario_fisica_dei_solidi_e_dei_fluidi.tex` 试摄入三条公式：理想气体状态方程（条件“理想气体，平衡态”）、气体分子方均根速率、牛顿流体剪切关系。每条记录原表达式、规范表达式、符号量纲、出处行、修改说明、源文件 SHA-256 与研究状态，并附 BSD-3-Clause 许可原文，保留原版权主体 Grufoony 与所选文档署名 Marco Caporale；新增的中文名称与类型注释属于规范化补充，不借用上游对本产品背书。样例数据与许可原文保存在归档标签 `archive/sadd-v4.0` 中，正式摄入时按 CORE-16 的源数据目录重新登记到 `packs/`。

记号提醒：样例中的 `n_{mol}`（物质的量）和 `V_x`（速度分量）只是研究用标识。国内大学物理教材通行 pV = νRT（ν 为物质的量）与 p = nkT（n 为分子数密度），速度用小写 v；样例中 V 同时表示体积，与 `V_x` 冲突。转为课程条目时按符号 ID 与记号方案（CORE-07）重新映射显示。

这三条只证明“可以追溯地获取、规范化并登记许可”，不证明已构建公式库或课程已覆盖；导入后仍需 AST 编译、语义与适用条件检查和双人审校。

采集与评测规范：

- **同意**：书写者书面同意，写明用途（训练或评测）、保存期限与撤回方式；未满十四周岁的书写者须取得监护人同意。
- **去标识**：只保存笔迹、匿名书写者编号、设备类型和书写方式（触屏、手写笔、纸面拍照），不采集姓名、学校等身份信息。
- **标注**：按 CORE-06 的 LaTeX 子集与规范化规则标注，双人标注，不一致的由第三人裁决。
- **隔离**：按书写者划分训练集、验证集与评测集；评测集冻结并记录哈希，不得用评测集调参；用于忠实转写验收的“故意写错”样本单独成集（CORE-31）。
- **分层**：评测样本标注书写方式、拍摄条件（清晰、阴影、弱光、倾斜、复杂背景）与复杂度（单行、分式、上下限、矩阵、多行），并比较原图、灰度与增强三组结果（CORE-30）。

整页检测与分割器作为可插拔后端（CORE-29），代码与权重许可同样登记。AGPL-3.0 许可的实现不进入主线依赖，评估只在实验分支进行（附录 B）。

冻结规则：

1. 网络转录只作线索，不作冻结依据。教育部教育考试院网站“考试大纲”栏目最新只有 2022 年数学大纲且正文为空（S17）；第三方转录互相矛盾且有错，例如有媒体称 2027 年数三“新增边际与弹性”，而 2025 年大纲原文已有“导数的经济意义（含边际与弹性的概念）”；另有网站把常系数线性微分方程组列入数一，而数一原文没有这一项（S20）。
2. 大纲条目记录 kp_id、适用科目集合、要求层级、纸本页码、两位转录人与冻结时间。资源包只携带 kp_id、自编摘要与页码，不复制大纲全文。
3. 新一年大纲发布后按同一流程转录，与上一版逐条比对；差异生成新的 syllabus_id 与条目修订，旧版本保留，用户按目标考试年份选择。
4. 带星号不等于不考：同济版中伯努利方程、欧拉方程、混合积、二元函数二阶泰勒公式、通量与散度、环流量与旋度带星号，但数一要考；方程的近似解、积分表的使用、微分与定积分的近似计算、幂级数的应用不带星号，却不在考纲内。
5. 无公式的知识点（纯概念辨析）显式标为 `concept_only` 并配概念卡后计入覆盖。
