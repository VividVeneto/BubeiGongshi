## 📦 通用资源包的边界

资源包是平台无关的 UTF-8 数据、字体、图片和模型权重集合，Android/Windows 对同一内容使用相同 pack ID、版本和 hash。平台加载位置、字体注册 API、native 推理运行时属于适配器，不能要求同一 `.so/.dll` 在两端使用。

| 包 | 内容 | 安装方式 |
| --- | --- | --- |
| bootstrap | 最小符号/字体、SI/常数表、必要本地化、学习示例 | 随安装包，仍经统一资源目录和验证器加载，首次启动不联网 |
| university-calculus | 同济高数范围及考试标签 | 主动下载/离线导入 |
| university-linear-algebra | 行列式、矩阵、线性空间、特征值、二次型 | 主动下载/离线导入 |
| university-probability-statistics | 概率、分布、随机变量、统计推断 | 主动下载/离线导入 |
| university-physics | 公共物理课程公式与条件 | 主动下载/离线导入 |
| high-school-* | 仓库历史 H01 高中数学/物理内容 | 独立分包，不替代大学内容 |
| model-hmer-* | 权重、词表、预处理与 decoder 配置、模型卡 | 不随主包，用户主动安装 |
| font-extension / locale-* | 扩展字体、本地化与语义朗读 | 按需加载，与许可清单关联 |

“资源剥离”指课程/字体/模型可独立构建和版本化，不要求 bootstrap 首次在线获取。渲染库自带字体需在构建时纳入同一资源目录/清单；字体按实际单独许可处理，不能把程序代码许可证直接视为字体许可。

## 🛡️ 清单、签名与激活

### 格式契约

包以受限 ZIP 容器示意，`manifest.json` + `manifest.sig` + `entries/`，最终格式在 M0 冻结。清单原始 UTF-8 字节参与签名，不允许 JSON 重排后“重验签”；解析器拒绝重复 key 和非标准数值。签名使用 Ed25519，条目用 SHA-256；不同时引入多套哈希算法。

```json
{
  "format_version": 1,
  "pack_id": "university-physics",
  "pack_version": "1.0.0",
  "security_epoch": 1,
  "key_id": "content-2026-a",
  "engine_abi_major": 1,
  "ast_schema": 1,
  "compatible_app": ">=1.0.0 <2.0.0",
  "dependencies": [],
  "entries": [],
  "licenses": [],
  "provenance": []
}
```

该示例只展示字段，不是可发布空包。发布验证器必须拒绝缺少内容、许可、来源的课程/模型包。每个 entry 含相对路径、类型、解压长度、SHA-256、逻辑 ID；课程条目另含 scope/来源/校验 schema，模型另含 tensor、词表和内存约束。

### 安装顺序和攻击面

1. 下载至私有 staging，断点续传按内容 hash 和长度校验；公开包下载不上传学习数据。
2. 读取受限清单（初始≤1 MiB）和签名，使用程序内置/受信更新的公钥根验签；先验证签名再处理内容。
3. 验证版本、依赖无环、ABI/AST/格式兼容、条目数量≤10000。初始包压缩体积≤256 MiB、解包≤512 MiB、单条≤128 MiB，模型若需例外必须另经预算 ADR，不能无限解压。
4. 限制压缩比≤100，拒绝绝对路径、`..`、盘符/UNC、混淆斜线、重复路径、NTFS ADS、保留设备名、符号链接/重解析点和平台大小写碰撞。只将经过规范化且保持在目标私有目录的相对路径解包。
5. 流式解压、逐项验证长度/hash；模型不含任意代码/custom ops 动态库，图算子/张量维度受限。签名不代表模型天然安全，解析器与运行时仍需预算。
6. 以内容 hash 创建新的只读版本目录，写入完成标记，fsync/平台等价持久化后切换小型 `active.json` 指针。正在读取旧包的会话继续使用旧句柄，结束后回收。
7. Windows 若 rename 因句柄占用失败保留旧指针，延迟激活，不覆盖原目录。崩溃恢复只接受有完成标记且验证过的目录，删除未激活 staging。

离线导入遵守相同验签流程；用户自定义公式是用户数据，不伪装成受信课程包。开发者 unsigned 模式只在开发构建，正式版本不可从隐藏开关绕过。

### 信任根、防降级和回退

清单签名加版本号不足以完全防止重放、冻结和签名密钥失窃。正式在线更新采用成熟 TUF 客户端/框架的 root、targets、snapshot、timestamp 元数据流程，参考规范 [S06]，不自己设计不完整“类 TUF”协议。离线 bootstrap 与离线包走受信根和兼容策略，不依赖首次联网取得 timestamp。

信任根离线保管，发布自动化只持有限 targets 权限；根轮换由旧/新阈值签名验证，密钥撤销和安全 epoch 随应用或已受信根更新。客户端记住已见的最高安全序号/元数据版本，过期或时钟异常暂停在线更新并提示，现有已验证内容仍可使用。

“内容版本回退”和“安全防降级”分开：仅允许回到本机已验证、未撤销、同一允许安全 epoch 且与当前应用兼容的最近良好内容版本；拒绝任意远端旧包。禁止把安全 epoch 回退作为普通修复手段。应用版本/数据库迁移回滚另按总体设计处理。

## 📚 课程范围与质量管线

### 覆盖矩阵

“同济高数 + 考研数学全部范围”不能只做一个高数目录。下面是待内容负责人按选定教材/考试年份逐项冻结的交付目录，不冒称已经对照了指定年度官方大纲。

| 模块 | 范围分解 | 必须带的条件/标签 |
| --- | --- | --- |
| 一元微积分 | 函数、极限、连续、导数/微分、中值定理、不定/定积分、反常积分与应用 | 定义域、连续/可导、积分收敛、教材章节 |
| 多元与向量分析 | 空间解析几何、向量、多元微分、重积分、曲线/曲面积分、场与积分定理 | 坐标系、区域/方向、场类型、边界光滑性 |
| 方程与级数 | 常微分方程、数项/幂级数、傅里叶级数及相应应用 | 初值/边值、收敛区间、适用条件 |
| 线性代数 | 行列式、矩阵、方程组、向量组/空间、相似/特征、二次型 | 维数、秩、可逆性、对称/正定条件 |
| 概率统计 | 概率、随机变量/向量、数字特征、极限定理、抽样、估计、假设检验 | 分布参数域、独立性、样本量、统计假设 |
| 大学物理 | 力学、振动/波、热学、电磁、光学、相对论与量子基础 | SI、约定符号、近似条件、物理情境 |
| 历史高中扩展 | 数学/物理分包，对应既有 H01 | 教育阶段、教材/版本，避免与考研 scope 混用 |

条目带 `textbook_id/edition/chapter`、`syllabus_id/year`、`exam_scope`（数一/数二/数三可多选）、`education_level`。没有确认适用大纲的条目标记 `scope_review_pending`，不得计入“考试范围已覆盖”。教材全文/例题/图示与公式事实分开，不默认复制受版权保护的解释与排版。

### 摄入与审校

```mermaid
flowchart LR
    accTitle: 课程公式资源摄入流程
    accDescr: 开源来源先通过许可筛选，然后只提取数据并规范化，经类型和人工审校后才能进入签名课程资源包。
    source["候选来源与固定版本"] --> license["逐文件许可检查"]
    license --> extract["数据提取，不执行 TeX"]
    extract --> normalize["规范 LaTeX、符号和条件"]
    normalize --> validate["AST / 量纲 / 样例验证"]
    validate --> review["数学物理人工审校"]
    review --> sign_pack["范围报告、许可清单和签名发布"]
```

处理器只读取文本/数据，不执行 `latex`、仓库脚本、notebook 或宏。去重使用规范 AST+条件+符号映射的 hash，不只比较 LaTeX 字符串。量纲通过不能证明公式物理正确；审核人必须检查来源、系数、符号含义、边界和适用条件。至少内容作者与独立审校者两人确认发布条目。

## 🧪 模型、许可与供应链门禁

内容包生成机器可读 provenance：来源 URL、固定 revision、文件/行或 item ID、取得日期、原 hash、许可证 SPDX/文本、作者、修改记录、审校者、schema 与范围。无法确认某图/段落的权利时排除该项；不能从仓库根许可证自动推断它包含的第三方教材页、字体和数据均相同许可。

模型包另带训练代码许可、权重许可、数据来源/授权、架构、词表、预处理、tensor shape、量化精度、运行时版本、设备基准和模型卡。量化/ONNX 导出不会自动改变原权重许可。用户图像默认不作为训练数据。

依赖工具生成 SBOM 和 THIRD_PARTY_NOTICES，内容工具生成 provenance 与版权清单。应用发布许可证当前仓库未明确，不因摄入 BSD 内容擅自替整个项目设置开源许可证。资源许可不明确的项不进入正式包。
